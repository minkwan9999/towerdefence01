# 구글 플레이 출시 가이드 (협곡 방어전, 무료 앱)

## 0. 한 번만 하는 준비

### 0-1. 업로드 키를 GitHub에 등록
업로드 키 파일(`canyonhold-upload.jks`)과 비밀번호는 저장소에 넣지 않고 따로 전달했습니다. **잃어버리지 않게 안전한 곳(클라우드 드라이브 등)에 두 군데 이상 보관하세요.**

GitHub 저장소 → Settings → Secrets and variables → Actions → New repository secret 에서 2개를 만듭니다.

| 이름 | 값 |
|---|---|
| `CH_KEYSTORE_B64` | `canyonhold-upload.jks.base64.txt` 파일 내용 전체 |
| `CH_KEYSTORE_PASSWORD` | `password.txt` 파일 내용 |

### 0-2. 무료 앱으로 등록
- 결제 프로필(판매자 계정)은 지금 필요 없습니다. 나중에 광고·앱 안 결제를 붙일 때 만들면 됩니다.
- **무료로 만든 앱은 유료로 바꿀 수 없습니다.** 돈을 받고 싶어지면 광고·앱 안 결제를 붙이거나, 유료 버전을 새 앱(다른 패키지 이름)으로 내야 합니다.

## 1. 앱 파일(AAB) 만들기
GitHub → Actions → **Android 앱 빌드** → Run workflow
- versionCode: 처음 `1`, 올릴 때마다 `2`, `3` … (같은 숫자는 다시 못 씀)
- versionName: `1.0.0` 처럼 이용자에게 보이는 버전

끝나면 실행 화면 아래 Artifacts 에서 zip 을 받습니다.
- `app-release.aab` → 플레이 콘솔에 올리는 파일
- `app-release.apk` → 내 안드로이드 폰에 직접 설치해 미리 확인하는 파일

## 2. 앱 만들기 (플레이 콘솔 → 앱 만들기)
| 항목 | 입력 |

- 약물·술·담배: 없음
- 도박·모의 도박: 없음
- 공포: 없음

## 7. 테스트 → 프로덕션 (개인 계정)
2023년 11월 이후 만든 **개인 개발자 계정**은 프로덕션에 바로 출시할 수 없고,
**비공개 테스트에 테스터 12명 이상이 14일 동안 참여**해야 프로덕션 신청이 열립니다.
1. 테스트 및 출시 → 비공개 테스트 → 트랙 만들기 → AAB 업로드
2. 테스터 이메일(구글 계정) 12명 이상 등록 → 참여 링크 공유
3. 테스터는 참여 링크로 테스트 버전을 설치합니다
4. 14일 뒤 프로덕션 액세스 신청 → 프로덕션 트랙에 AAB 업로드 → 검토 제출

## 8. 업데이트할 때
1. 게임(루트 `index.html`)을 고친 뒤

3. 플레이 콘솔에서 새 버전 만들기 → AAB 업로드
