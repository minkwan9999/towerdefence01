# 협곡 방어전 (Tower Defence 01)

경찰차, 소방차, 덤프트럭, 범퍼카, 택시, 크레인, 후룸라이드, 탱크 등 차량 8종을 길목에 세워 색깔별 젤리 군단의 20개 웨이브를 막아내는 브라우저 타워 디펜스 게임입니다.

## 플레이

- 배포 주소: https://minkwan9999.github.io/towerdefence01/
- 로컬: `index.html`을 브라우저로 열면 바로 실행됩니다. 빌드 과정이 없습니다.

## 조작

| 키 | 동작 |
|---|---|
| `1`–`8` | 차량 선택 |
| 클릭 / 탭 | 빈 칸에 배치, 세운 차량 선택 |
| `Space` | 웨이브 시작 |
| `U` / `X` | 선택한 차량 강화 / 판매 |
| `P` | 일시정지 |
| `Esc` / 우클릭 | 선택 취소 |

## 차량

| 차량 | 비용 | 능력 |
|---|---|---|
| 경찰차 | 50 | 빠른 연사 |
| 소방차 | 70 | 물대포로 둔화 |
| 덤프트럭 | 90 | 돌 투하 범위 피해 |
| 범퍼카 | 60 | 들이받아 뒤로 밀어냄 |
| 택시 | 80 | 공격 없음, 웨이브마다 요금 수입 |
| 크레인 | 120 | 쇠공 낙하, 강한 한 방 |
| 후룸라이드 | 130 | 주변 전체 물보라 + 둔화 |
| 탱크 | 160 | 최장 사거리 포격 |
